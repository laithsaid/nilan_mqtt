The unit — Comfort 300 LR (right model), layout after Nilan's installation manual, live values

Values — last reading. ⓘ = what it is, allowed values. Rows with "Set" may be changed by Home Assistant and this page.

Week schedule — run by this program

The Nilan's own week programs (1-3) can only be chosen over Modbus (Values → Week program); their times can't be read or changed on this controller. This schedule sets the ventilation step and/or room setpoint when each period starts; a change from the panel, this page or Home Assistant stays until the next period. Saving applies the current period at once. Home Assistant: switch.nilan_schedule, sensor.nilan_schedule_next.

Empty step or temperature = leave it as it is.

Clock — the Nilan controller's own clock (week programs, alarm log)

Modbus — serial port and the Nilan unit

Nilan CTS 602 default: 19200 baud, even parity, 8 data bits, 1 stop bit, unit 30. Serial port simulate = a fake unit for testing.

MQTT — Home Assistant's broker

Registers — what is read and what may be written

Off = not read, not in Home Assistant. Read = sensor. Write = Home Assistant (and this page) may change it, only between min and max. Only holding registers the Nilan spec allows can be set to write. ⓘ = description.
